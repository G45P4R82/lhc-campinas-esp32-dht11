01 · O projeto

ESP32 + DHT11

Um sensor de ambiente lê temperatura e umidade, conecta ao Wi-Fi e envia os dados para um broker MQTT.

Entrada

DHT11 conectado ao ESP32.

Processamento

Firmware Arduino calcula e organiza a leitura.

Saída

Dados publicados para sistemas IoT.

03 · MQTT 1/4

O que é MQTT?

MQTT é um protocolo leve de mensagens para dispositivos IoT. O sensor não precisa conhecer diretamente quem vai consumir seus dados.

Leve

Mensagens pequenas e baixo consumo.

Assíncrono

Quem publica não precisa chamar cada receptor.

Desacoplado

O broker separa quem envia de quem recebe.

04 · MQTT 2/4

Cliente, broker e tópico

Cliente

ESP32, computador ou aplicação conectada.

Broker

Servidor que recebe, organiza e entrega mensagens.

Tópico

Endereço lógico da mensagem, como sensores/.../ambiente.

Publish envia. Subscribe assina para receber.

05 · MQTT 3/4

Como uma mensagem viaja?

O cliente publica no broker; o broker entrega aos clientes inscritos no tópico.

07 · Circuito

Montagem do DHT11

Altere somente isto: troque o fio de alimentação de 3V3 para VIN. DATA permanece no GPIO5 e GND permanece no GND.

08 · Circuito

Conexões e materiais

Conexões

DATA → GPIO5
VCC → VIN
GND → GND

Materiais

ESP32, DHT11, protoboard, jumpers e cabo USB.

Bibliotecas

DHT sensor library, Adafruit Unified Sensor e PubSubClient.

O código usa #define DHTPIN 5. A referência antiga ao GPIO4 não corresponde ao firmware atual.

12 · Código 4/8

setup(): início

void setup() {
  pinMode(STATUS_LED, OUTPUT);
  setLed(false);
  Serial.begin(115200);
  dht.begin();

  mqttClient.setServer(MQTT_HOST, MQTT_PORT);
  mqttClient.setCallback(mqttCallback);
}

Executa uma vez: prepara LED, serial, DHT11 e MQTT.

13 · Código 5/8

loop(): ciclo principal

void loop() {
  connectWiFi();
  if (!connectMqtt()) return;

  mqttClient.loop();

  if (millis() - lastPublish >= 30000) {
    lastPublish = millis();
    publishReading(false);
  }
}

Garante conexões, processa mensagens e publica sem bloquear o relógio.

14 · Código 6/8

Conexão Wi-Fi e MQTT

void connectWiFi() {
  if (WiFi.status() == WL_CONNECTED) return;
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    blinkLed(2, 100, 100);
    delay(900);
  }
}

bool connectMqtt() {
  if (mqttClient.connected()) return true;
  if (millis() - lastMqttAttempt < 5000) return false;
  lastMqttAttempt = millis();
  return mqttClient.connect(DEVICE_ID, MQTT_USERNAME, MQTT_PASSWORD);
}
15 · Código 7/8

Comandos recebidos

void mqttCallback(char* topic, byte* payload,
                  unsigned int length) {
  String command;
  for (unsigned int i = 0; i < length; i++) {
    command += static_cast<char>(payload[i]);
  }

  if (command == "read") publishReading(true);
  if (command == "restart") ESP.restart();
}

read pede leitura imediata. restart reinicia o ESP32.

16 · Código 8/8

Sensor, JSON e publicação

float humidity = dht.readHumidity();
float temperatureC = dht.readTemperature();
float heatIndexC = dht.computeHeatIndex(
  temperatureC, humidity, false);

char payload[384];
snprintf(payload, sizeof(payload),
  "{\"temperature_c\":%.2f,\"humidity\":%.2f}",
  temperatureC, humidity);

mqttClient.publish(MQTT_TOPIC, payload);

17 · Configuração

Agora configure o secrets.h

Copie secrets.example.h para secrets.h e preencha com os seus valores.

#define WIFI_SSID "NOME_DA_SUA_REDE"
#define WIFI_PASSWORD "SENHA_DO_WIFI"
#define MQTT_HOST "ENDERECO_DO_BROKER"
#define MQTT_PORT 1883
#define MQTT_USERNAME "SEU_USUARIO_MQTT"
#define MQTT_PASSWORD "SUA_SENHA_MQTT"

Nunca publique este arquivo. Ele já está protegido pelo .gitignore. Se uma senha real foi exposta, troque-a no broker.

18 · Build

Compile o firmware

arduino-cli lib install \
  "DHT sensor library" "Adafruit Unified Sensor" PubSubClient

arduino-cli compile \
  --fqbn esp32:esp32:esp32 \
  lhc-campinas-esp32-dht11
  1. Conecte o ESP32 por USB.
  2. Use o diretório do projeto.
  3. Se aparecer erro de biblioteca, instale as três dependências.
19 · Burn / Upload

Grave no ESP32

arduino-cli upload \
  -p /dev/ttyUSB0 \
  --fqbn esp32:esp32:esp32 \
  lhc-campinas-esp32-dht11
  1. Confira a porta: normalmente /dev/ttyUSB0.
  2. Se não iniciar, segure BOOT.
  3. Pressione e solte EN/RESET.
  4. Solte BOOT quando começar o upload.

21 · Teste MQTT

Consulte os dados recebidos

Substitua os nomes pelas credenciais do seu secrets.h.

mosquitto_sub \
  -h MQTT_HOST -p MQTT_PORT \
  -u MQTT_USERNAME -P MQTT_PASSWORD \
  -t "sensores/iot-sensor-externo-lhc-001/#" -v

Você deverá ver mensagens de ambiente, resposta e status.

22 · Comando MQTT

Peça uma leitura imediata

mosquitto_pub \
  -h MQTT_HOST -p MQTT_PORT \
  -u MQTT_USERNAME -P MQTT_PASSWORD \
  -t "comandos/iot-sensor-externo-lhc-001/cmd" \
  -m "read"

Enquanto o mosquitto_sub estiver aberto, a resposta aparecerá no tópico sensores/.../resposta.
