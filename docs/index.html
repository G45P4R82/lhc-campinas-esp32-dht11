ESP32 + DHT11

Como o firmware lê o ambiente, conecta ao Wi-Fi, publica dados via MQTT e como gravar o ESP32 e publicar esta apresentação no GitHub Pages.

Projeto: iot-sensor-externo-lhc-001 · Campinas

Slide 02 · Preparação

Hardware e ligações

Componentes

ESP32 DevKit/WROVER, DHT11, cabo USB/CP2102 e resistor de pull-up de 10 kOhm quando o módulo não tiver resistor integrado.

DHT11

DATA → GPIO 5, VCC → 3V3 e GND → GND. O código usa #define DHTPIN 5.

Bibliotecas

DHT sensor library, Adafruit Unified Sensor e PubSubClient.

Atenção: o README original menciona D4/GPIO4, mas o código usa GPIO5. A ligação precisa seguir o código ou o valor de DHTPIN deve ser alterado.

Slide 03 · Firmware

Como o código funciona

  1. setup()
    Configura LED, serial, DHT11, broker MQTT e callback de comandos. A primeira publicação fica preparada para acontecer logo após a conexão.
  2. loop()
    Garante Wi-Fi, tenta MQTT, processa mensagens com mqttClient.loop() e publica a cada 30 segundos.
  3. publishReading()
    Lê temperatura e umidade, calcula sensação térmica, monta JSON e publica no tópico adequado.
  4. LED de status
    O LED no GPIO2 é ativo em nível baixo: LOW acende e HIGH apaga.
if (millis() - lastPublish >= PUBLISH_INTERVAL_MS) {
  lastPublish = millis();
  publishReading(false);
}

Slide 05 · Upload

Como gravar o ESP32

  1. Instale o Arduino IDE, o suporte para placas ESP32 e as bibliotecas do projeto.
  2. Copie secrets.example.h para secrets.h e preencha Wi-Fi e MQTT. Nunca publique esse arquivo.
  3. Abra o arquivo lhc-campinas-esp32-dht11.ino, selecione ESP32 Dev Module e a porta USB.
  4. Compile e faça upload. Se necessário, segure BOOT, pressione e solte EN/RESET, depois solte BOOT.
  5. Abra o Monitor Serial em 115200 baud e observe conexão, leitura e publicação.
arduino-cli lib install "DHT sensor library" "Adafruit Unified Sensor" PubSubClient
arduino-cli compile --fqbn esp32:esp32:esp32 lhc-campinas-esp32-dht11
arduino-cli upload -p /dev/ttyUSB0 --fqbn esp32:esp32:esp32 lhc-campinas-esp32-dht11
arduino-cli monitor -p /dev/ttyUSB0 --config baudrate=115200
Slide 06 · Publicação

Como publicar no GitHub Pages

  1. Faça commit e push deste projeto para o GitHub. A apresentação está em docs/index.html.
  2. No repositório, abra Settings → Pages.
  3. Em Build and deployment, escolha Deploy from a branch.
  4. Selecione a branch main e a pasta /docs; clique em Save.
  5. Aguarde o workflow terminar. O endereço será parecido com:
    https://G45P4R82.github.io/lhc-campinas-esp32-dht11/
git add docs/index.html README.md
git push origin main
